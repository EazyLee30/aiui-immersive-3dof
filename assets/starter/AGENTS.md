# Spatial reference project

This is an editable starting point, not a finished product or hardware certification.

Keep scene coordinates separate from the host sensor adapter. Draw and hit-test the same projected geometry. Menu selection belongs only to temple swipes; the menu returns no gaze targets. Recenter needs a fresh pose and captures full orientation. Keep physical gesture mappings configurable after observing the target host.

The supplied display profile is 480×352 monochrome with a design focal length, not a universal device FOV. Change viewport, projection and hit-test center together. The native pixel font is bundled with its OFL notice. Keep that notice with any copied font.

Before declaring a new application ready, run official AIX checks, inspect a package, validate target behavior and report untested physical interactions. Do not ship browser preview dependencies or sensor simulation as native production capabilities.
